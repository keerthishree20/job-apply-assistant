# Job Apply Assistant

End-to-end AI-powered job application automation. Parses job descriptions, tailors resumes with Gemini AI, generates cover letters, and auto-submits via LinkedIn Easy Apply and ATS portals using Playwright.

## Tech Stack

`Python` `Next.js` `TypeScript` `Google Gemini` `Playwright` `FastAPI`
